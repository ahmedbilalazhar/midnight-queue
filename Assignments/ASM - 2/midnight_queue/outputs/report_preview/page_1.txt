Which Section 3.4 properties does the raw file already have? Its Time column is non-decreasing and its rows are in txn_id order, so it is
exactly C1 (and supplies C6’s input sequence). It is not C3: only 50.6% of adjacent pairs are in triage order versus 67.4% for band alone,
with 20.303B triage inversions. C2 and C5 require seeded construction; C4 is the exact reverse of C3; C6 changes the comparator to band
alone.
B. Build the Contenders
The package src/midnight_queue/ contains Insertion Sort (in-place shifting), top-down stable Merge Sort, Naive Quick Sort (last-pivot Lomuto,
iterative stack), Hardened Quick Sort (median-of-three, three-way partition and a depth-limited in-place heap fallback), bottom-up Heap Sort,
a size-K heap selector (the root is the worst retained case: a min-heap on the score with the descending comparator reversed), a bounded
insertion buffer with binary search and explicit shifting, and all three live-feed strategies. No built-in or NumPy sort appears inside a contender;
sorted() is confined to the labelled reference/verification code and to deterministic input preparation. A key comparison is one call to the
central TriageOrder.cmp; a move is one record assignment (a swap is three). Full-sort/Top-K timers exclude CSV I/O, risk scoring, condition
construction, input copying and verification. The fallback guarantees worst-case O(n log n) time without altering the required naive Lomuto
contender.
Correctness and the C6 clash. The automated suite has 91 passing tests, including empty input, one record, all-equal keys, duplicate-heavy
input, every condition and size, Class perturbation, Top-K boundaries and live-feed publication. C1–C5 use a total key and are checked for
exact sequence equality with the reference. C6 is defined by the PDF as band alone, so it has huge ties; a literal C6 result is checked as
a permutation with non-increasing bands and no access to Amount, Time, txn_id or Class. Band-only comparison does not define a unique
row sequence; a full-key reference would impose extra criteria. This is the disclosed specification clash. The literal band-only comparator
is retained and tested without secondary-field access. Conditions are C1 arrival, C2 seeded shuffle, C3 pre-ranked, C4 reverse-ranked, C5
with floor(0.01n) records deranged, C6 band-only.
